# Beauty Timer

A countdown and countup timer app designed for beauty school students and professionals in Japan.

## About This App

Beauty Timer is a simple, offline timer application for cosmetology students, hair stylists, estheticians, and beauty school instructors. It helps users accurately time beauty treatments and practice sessions such as hair coloring, perming, and facial treatments.

### Features

- Circular drag ring to set the desired time (0 to 60 minutes)
- Countdown and countup timer
- Play / Pause / Reset controls
- Alert notification at a set elapsed time
- No login or account required
- Fully offline — no internet connection needed

### Target Users

- Cosmetology students at beauty vocational schools (専門学校)
- Licensed hair stylists and colorists
- Estheticians and skin care specialists
- Nail technicians
- Beauty school instructors and educators
